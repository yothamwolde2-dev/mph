# MPH

My Personal Hub. Projects, tasks, weekly goals, learning and an HTML document reader, in one private app for Mac and iPhone.

## Install on iPhone

Open the app address in Safari, tap Share, then Add to Home Screen.

## Install on Mac

Open the app address in Safari, then File, Add to Dock. In Chrome use the install icon in the address bar.

## Using it

* Home: your day, weekly goals, project pulse and recent documents. Tap Customize to rename the greeting and show, hide or reorder sections.
* Projects: topics, projects, deliverables and sub items with five statuses. Progress fills in automatically.
* Tasks and Week: everything with a date, plus weekly goals and a reflection.
* Learning and Library: upload HTML files and read them inside the app. Each document keeps its own saved progress on every device.
* Undo and redo sit in the top bar (Cmd Z and Cmd Shift Z on the Mac).

See `CLAUDE.md` for how it is built and the roadmap, and `CHANGELOG.md` for versions.
